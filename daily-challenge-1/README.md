# Daily Challenge 1: Terminal-Only Project Setup

This is a starter structure for practising command-line project creation.

## Structure

```text
daily-challenge-1/
├── src/
│   ├── index.html
│   ├── css/style.css
│   └── js/app.js
└── README.md
```

## Try it yourself

From the repository root in Git Bash, create the folders with `mkdir -p`, then create the files with `touch`. Record the exact commands you personally run in `terminal-log.md`.
